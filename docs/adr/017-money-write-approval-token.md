# ADR-017: Single-use approval token for Money writes (Ed25519 JWT)

- Status: accepted (Erik, #144 — 31. 10. 2026)
- Context: CLAUDE.md §7 — the main app ↔ bridge use HMAC, and **writes need a single-use approval JWT**. Phase 3f
  brings the first write (CRM activity after a sent invoice / reminder); Phase 4 adds documents.

## Decision

1. **Ed25519 (EdDSA) JWT**, library **PyJWT[crypto]** in the app and the bridge (no hand-made JWS).
2. The **app signs** with `APPROVAL_JWT_PRIVATE_KEY` (VPS `deploy/.env`, chmod 600, PEM or one base64 line;
   generated by `install.sh` / `deploy/approval-key.sh`, never printed or logged). The **bridge verifies** with
   `APPROVAL_JWT_PUBLIC_KEY` (Windows `.env`).
3. Claims: `act` (e.g. `activity.create`), `company_id`, `person_id`, `sha256` of the exact request body, `iat`,
   `exp` (≤ 5 min), `jti`. The bridge refuses a wrong action, a body that does not match, an expired token, a
   lifetime over 5 min, another company than the body, and a `jti` used before (in-memory, one process — ADR-016).
4. HMAC still signs the request; a token alone is not enough. No public key → the bridge accepts **no** writes.
5. People control writes with Settings 13a „Zápisy do Money povolené“ ⚠ (default off, re-auth, audit). The activity
   is written **automatically after the person's send** (the send is the approval), only with 13d on and the activity
   types chosen from Money's codebook. Only the subject and invoice numbers go to Money — never a mail body.
6. Idempotency `SMID:<draft_id>`; a mutation is **never retried automatically**. Failures are listed in 13d for a
   manual retry. On the real API the write answers 501 `waiting_for_probe` until the probe confirms the required
   fields of `Activity` and the REST filter for the SMID check.

## Consequences

- Phase 4 writes (delivery notes, orders, complaints) reuse the same token with their own `act`.
- Key rotation: run `deploy/approval-key.sh` after deleting the old line, copy the new public key to the bridge,
  restart both; tokens older than 5 min are worthless anyway.
