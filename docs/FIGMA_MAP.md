# FIGMA_MAP.md — every screen ID → its frame in the Figma file (v2.10)

Figma file: https://www.figma.com/design/vBDv8OCQTjxPBMzq6KBcHU (Smart Mail – grafický návrh v1.0, 26. 10. 2026; 355 frames).

How to use (DECISIONS D24):
- Before building or changing a screen, open **every** frame of its screen ID below with the Figma MCP server
  (`get_design_context` with the node id; `get_screenshot` to compare). The first frame of each ID is the default
  state, the others are states/variants — each state in SCREENS_SPEC must look like its frame.
- **Behaviour, texts, rules** = the spec files (DECISIONS wins). **Look** (layout, spacing, colours, icons, sizes) = Figma.
  If Figma and a spec disagree about behaviour, follow the spec and report it; about the look, follow Figma.
- Colours, type, spacing come from `design/tokens.json` / `web/src/styles/tokens.css` — the same values as the Figma
  variables (Color Light/Dark, Size). Never copy hex values from Figma code output; map them to tokens.
- Node ids are stable while frames are not deleted. If a link is dead, find the frame by its name on the page listed.
- Pages: 00 Cover `0:1` · 01 Foundations `2:2` · 02 Components `2:3` · 03 Patterns `2:4` · 04 Web `2:5` ·
  05 Mobile `2:6` · 06 Flows `2:7` · 07 Handoff `2:8` · 08 Roundcube reference `2:9`.
