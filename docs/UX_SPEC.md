# UX_SPEC.md — design system, layouts, screens and interactions

This file is the single source of truth for the UI. Figma (FIGMA.md) and code (React + Tailwind + shadcn/ui) implement
exactly these tokens, components and screens. All UI copy is Slovak; Roundcube SK wording is preferred wherever an
equivalent exists (see PRODUCT_SPEC §1).

---------------------------------------------------------------------------------------------------
## 1. Design principles
1. **Roundcube skeleton, modern skin** — left rail, folder column, message list, reading pane; toolbar with icon +
   label under it; same names, same order, same places as the customer's Roundcube (screenshots in
   `design/reference/roundcube/`, DECISIONS D19). Modern spacing, type and states.
2. **One AI accent** — violet is used only for AI (cards, assistant, ✦ icon). Blue = app actions. Never mix.
3. **Calm density** — default "Kompaktná" list (Roundcube users are used to it); "Pohodlná" adds AI summaries.
4. **Action proximity** — the action sits next to the information it needs (approve under the checks that justify it).
5. **Max 5 primary actions per view**; the rest in "Viac" / "⋯".
6. **States are designed, not left to chance** — every component has empty, loading, error, disabled, focus.

### 2.4 Spacing, radius, elevation, icons, motion
- Spacing scale (4-pt): 2, 4, 8, 12, 16, 20, 24, 32, 40, 48.
- Radius: `xs` 4 (checkbox, small chips), `sm` 6 (inputs, buttons), `md` 8 (cards, menus), `lg` 12 (panels, dialogs,
  AI card), `full` (pills, avatars).
- Elevation: `e1` 0 1 2 rgba(16,24,40,.06) (cards), `e2` 0 8 24 rgba(16,24,40,.12) (menus, popovers),
  `e3` 0 20 48 rgba(16,24,40,.20) (dialogs, drawers).
- Icons: **Lucide**, stroke 1.75; 20 px in toolbar/rail, 16 px inline, 24 px mobile nav. AI icon = `Sparkles`.
  Complete icon map: §2.8.
- Motion: hover 120 ms; panels/drawers 180 ms ease-out; toasts 200 ms; list item removal 160 ms collapse;
  `prefers-reduced-motion` → no transforms.
